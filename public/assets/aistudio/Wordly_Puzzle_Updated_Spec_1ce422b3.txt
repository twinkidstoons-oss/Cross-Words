3. GAME OVERVIEW
Build a polished Android-first word-search puzzle game using React Native and Expo.
Players choose a category and find hidden words in an 8×8 letter grid. The player
selects words by dragging across connected letters. Include Classic and Time modes,
hints, bonus words, score, coins, level progression, sound effects, and AdMob test ads.
Core gameplay must work offline; ads may require an internet connection.

5. FIXED GRID RULES — ALWAYS 8×8
- Every game, category, mode, and level must use exactly 8 rows × 8 columns.
- Do not use 10×10, 12×12, adaptive grids, scrolling grids, or oversized cells.
- The grid must remain fully visible and usable on common Android phone screens.
- Only place words of 3–8 letters. Never allow a word to extend outside the grid.
- Place words horizontally, vertically, and diagonally in either direction, where possible.
- Check every candidate placement is within bounds and does not create invalid coordinates.
- If a word cannot be placed after a reasonable number of attempts, skip it and choose
  another valid short word. Do not clip, wrap, or partially display a word.
- Fill all remaining cells with random uppercase letters.
- Keep cell dimensions responsive while preserving the 8×8 layout.

6. WORD SELECTION — BUBBLE-STYLE ONLY
Replace the standard flat/line selection appearance with a rounded bubble selection style.
- As the player drags across connected letters, show each selected letter inside a
  circular or pill-shaped bubble.
- Selected bubbles should have a clear, attractive fill, subtle shadow, and smooth animation.
- Keep the selected path visually connected and easy to follow.
- On a correct word, animate the selected bubbles into the word's assigned highlight color.
- On an incorrect selection, briefly show a gentle neutral/red feedback state, then reset.
- Do not draw a thick straight line through letters as the primary selection indicator.
- Support all eight straight-line directions and touch input through the full cell area.
- Ensure selection works smoothly on small screens and does not block scrolling outside
  the grid.

7. GAME MODES
Classic Mode:
- No time limit.
- Timer counts upward from 00:00.

Time Mode:
- Two-minute countdown starting at 02:00.
- Timer counts down.
- When fewer than 30 seconds remain, change the timer pill to a clear warning/red style.
- When time reaches zero, end the round and show the results screen.

8. SCORING
- Correct puzzle word: +10 points.
- Valid bonus word: +5 points.
- Time Mode completion bonus: remaining seconds × 2.
- Prevent the same puzzle word or bonus word from being scored more than once.

9. BONUS WORDS
Include a curated offline dictionary of at least 600 common English words, primarily
3–4 letters long, stored in a Set for efficient lookup.
A selected word qualifies as a bonus word only if it:
- contains at least 3 letters;
- exists in the curated dictionary; and
- is not one of the current puzzle's target words.
Award +5 points once per unique bonus word per puzzle.
Do not require an online dictionary or network request.

10. HINT SYSTEM
- Give each puzzle 3 free hints.
- Tapping Hint selects a random unfound target word.
- Briefly highlight that word's cells with a yellow bubble animation: 3 pulses over
  approximately 1.5 seconds.
- Show the remaining hint count on the lightbulb button.
- Disable the free hint button when no hints remain.
- Optionally offer a rewarded ad for an extra hint; grant it only after confirmed reward.

11. COINS AND LEVEL PROGRESSION
- Starting balance: 300 coins.
- Award 50 coins when a level is completed.
- Persist the coin balance using AsyncStorage.
- Category 1 / first level is unlocked by default.
- Unlock the next category after completing the preceding category/level.
- Persist completed level/category IDs using AsyncStorage.
- Prevent duplicate coin awards if the results screen is reopened.

16. TECHNICAL REQUIREMENTS
- Framework: React Native with Expo (latest stable SDK compatible with dependencies).
- Gesture handling: react-native-gesture-handler.
- Ads: react-native-google-mobile-ads.
- Persistence: @react-native-async-storage/async-storage.
- Navigation: expo-router.
- Sound: use a currently supported Expo audio package; keep sound effects local/offline.
- Android-first. iOS support is optional.
- Use TypeScript and reusable components where practical.
- Keep all core puzzle logic client-side and playable offline.
- No authentication, leaderboard, cloud sync, or mandatory backend.
- If a backend is retained, limit it to an optional health-check endpoint:
  GET /health → { "status": "ok" }.
- All user-facing text must be in English.
